# Snoolink Frontend

## 🎯 What is this

Snoolink -- landing page frontend built with a responsive,
performance‑first architecture and clean UI components. It provides the
public‑facing site for Snoolink, with pages for home, about, contact,
pricing, roadmap, privacy, terms, use‑cases, and more.

## 📁 Repository Structure

    /assets             → static assets (images, css, etc.)  
    .gitignore  
    CNAME               → custom domain config  
    LICENSE  
    README.md  
    about.html  
    contact.html  
    index.html          → main landing page  
    pitch‑deck.html     → pitch deck / marketing page  
    pricing.html        → pricing page  
    privacy.html        → privacy policy page  
    roadmap.html        → project roadmap page  
    snoolink_influencers.csv  
    snoolink_wall_of_fame.csv  
    terms.html          → terms of service page  
    use-cases.html      → use cases page  
    wall-of-fame.html   → wall of fame page  

## 🚀 Built With / Tech Stack

-   Standard HTML / CSS / JS for static pages\
-   Static asset folder (`assets/`) for images, styles, etc.\
-   MIT‑licensed

## 🛠️ How to Run / Deploy (for static HTML)

1.  Clone the repo

    ``` bash
    git clone https://github.com/snoolink/frontend.git
    ```

2.  Navigate to project folder

    ``` bash
    cd frontend
    ```

3.  Open `index.html` in your browser.
